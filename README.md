# Category Explorer

Aplikasi web modern berbasis React untuk mengeksplorasi kategori produk dari [Fake Store API](https://api.escuelajs.co/api/v1/categories). Aplikasi ini menampilkan daftar kategori secara dinamis, mendukung pencarian, pengurutan, tampilan grid responsif, serta mode gelap/terang.

---

## ✨ Fitur Utama

- **Ambil Data Langsung dari API:** Data kategori diambil secara real-time dari API eksternal.
- **Pencarian & Pengurutan:** Pengguna dapat mencari kategori berdasarkan nama dan mengurutkan berdasarkan nama atau ID.
- **Tampilan Grid Responsif:** Kategori ditampilkan dalam grid yang menyesuaikan ukuran layar.
- **Mode Gelap/Terang:** Tersedia toggle untuk mengubah tema aplikasi.
- **Penanganan Loading & Error:** Terdapat animasi loading dan tampilan error yang informatif.
- **Komponen Modular:** Struktur kode rapi dengan komponen terpisah untuk Header, SearchBar, dan CategoryCard.

## 🛠️ Cara Instalasi

1. **Clone repository:**
   ```bash
   git clone https://github.com/yourusername/category-explorer.git
   cd category-explorer
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Jalankan aplikasi secara lokal:**
   ```bash
   npm run dev
   ```

4. Buka [http://localhost:5173](http://localhost:5173) di browser Anda.

## 📄 Penjelasan Singkat

Aplikasi ini menggunakan React dan Vite untuk performa optimal. Data kategori diambil dari API eksternal, lalu ditampilkan dalam grid. Pengguna dapat mencari dan mengurutkan kategori, serta mengganti tema aplikasi. Semua komponen dibuat modular agar mudah dikembangkan.
